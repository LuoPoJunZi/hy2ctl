# Linux VPS 独立验收清单

此目录记录人工验收，不属于 `verify.sh all` 的自动化测试。不要把模拟 systemctl 的回放通过描述为真实 VPS 通过。

只使用可重建、无生产节点的测试 VPS；安装、证书切换、服务控制、恢复和卸载会修改系统。执行前需获得该测试机操作授权，不在开发电脑或生产机器直接运行。

## 验收记录

记录提交 SHA、系统发行版、面板/内核版本、证书模式、服务实际运行用户，以及每项实际结果。未执行的项目填写“未验证”，不要默认通过。记录不得包含密码、私钥或未匿名化的分享链接。

## 场景

- [ ] 一键安装后存在 `hy2` 命令与 Hysteria2 内核；无需下载 src 模块。
- [ ] 按默认值完成自签配置；服务保持运行，客户端证书固定校验可连通。
- [ ] 使用专门的测试域名完成 CA 配置；CA 与自签互相切换后文件与分享参数一致。
- [ ] 以 systemd 实际服务用户确认 config.yaml、server.crt、server.key 可读，私钥未对其他用户开放。
- [ ] 菜单启动、停止、重启与状态显示一致；输入 EOF 会取消，不意外部署或持续刷屏。
- [ ] 测试端口占用、证书生成失败等失败路径；config.yaml、meta.info、server.crt、server.key 及缺失标记恢复一致。
- [ ] 手动备份/恢复、诊断报告、面板更新及更新失败保护符合预期。
- [ ] 在专用测试环境模拟自动快照末项复制/发布失败，旧快照仍可恢复；旧版平铺快照升级后可读，手动备份不被自动清理。
- [ ] 模拟服务重启返回成功后进程退出，配置/手动恢复会回滚；回滚后的服务也失败时不会提示恢复成功。
- [ ] IPv4、IPv6 和 NAT/内网 VPS 的地址探测结果准确；外部探测失败时本机回退显示警告，分享地址与实际公网入口/UDP 端口映射一致。
- [ ] 单独验证卸载，只针对这台测试机；保留必要的匿名验收记录。
